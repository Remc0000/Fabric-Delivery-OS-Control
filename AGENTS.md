# Control repository boundary

This repository is public and specification-first. No executable workflow,
protection change, federation, or infrastructure bootstrap is authorized until
a human approves the applicable proposal and action. The human authorized only
the bounded synthetic approval proof on 2026-11-17. Its workflow still needs
human review and merge before dispatch; this is not runtime or cloud approval.

Never approve a workflow with a human token. The authorized human performs the
approval. Do not remove protections or use an unprotected environment as a
fallback.

Do not put private solution identifiers, mappings, manifests, prompts, code,
data, or detailed logs in this repository or its Actions surfaces. Use opaque
request references and explicitly permitted status only.

Future agent runtime identities have no write or administration rights here.
Proposed control upgrades require the separate human-reviewed upgrade path.
